API documentation

Read-only REST API, JSON over HTTPS. Same data and filters as the search page; every record carries its sources. Machine-readable schema: /openapi.json (OpenAPI 3). Use within the licence terms (sources & licences).

Quick start

curl "{{ base }}/api/v1/companies?q=endoscope*&sector=medtech&region=DE-BW&limit=10"
curl "{{ base }}/api/v1/stats?sector=pharma"
curl -o list.xlsx "{{ base }}/export.xlsx?product=W"

Search syntax in q: AND/OR/NOT (also UND/ODER/NICHT), brackets, "phrases", prefix*. Pagination with limit (max 1000) and offset; responses include total and facet counts.
